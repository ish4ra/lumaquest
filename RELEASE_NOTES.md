# LumaQuest v0.1.0-alpha.1 — Green Fields 3D

This release is the first playable build of LumaQuest's **full 3D redesign**.

The old side-scrolling prototype has been replaced by a third-person action-adventure/platformer foundation in **Godot 4.7.2**.

## Try this first

- Move with all four **Arrow Keys**
- Orbit the camera with the **Mouse**
- **Space** to jump, **Shift** to sprint
- **J** for sword attacks and a 3-hit combo
- **K** to dodge, **L** to guard, **Q** to lock on
- **F** to make Luma reveal hidden paths
- **E** to talk/open/interact
- Search the high ruins for a **key**, then open the ancient gate
- Find the hidden Luma crossing near the starting grove
- Reach the final arena

This is an alpha vertical slice: the current character/enemy/environment art is original procedural stylized geometry used to establish gameplay, composition and the new 3D direction before final modeled/animated assets are introduced.
